# CLI-Based Task Manager

## Project Description

This is a simple command-line Task Manager
developed using Python.

It allows users to add, view, complete and
delete tasks.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Input validation
- Logging messages

## Technologies Used

- Python
- Lists and Dictionaries
- Functions
- Modules
- Exception Handling

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

   python src/main.py
